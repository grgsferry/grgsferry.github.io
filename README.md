# Gregorius Ferry — Portfolio (Next.js)

## Setup

```bash
npm install
npm run dev
```

## Blog

To publish a new post, add a `.md` file to the `/posts` folder:

```
/posts/my-new-post.md
```

Each file needs a frontmatter block at the top:

```markdown
---
title: "Your Post Title"
date: "2024-12-01"
description: "A short one-liner shown on the blog listing page."
tags: ["Tag1", "Tag2"]
---

Your content here. Supports full Markdown:
- **bold**, _italic_
- Code blocks
- Tables (via GFM)
- Images
```

The slug comes from the filename: `my-new-post.md` → `/blog/my-new-post`.

Posts are sorted by `date` descending. Tags and description are optional.

## Deployment

The site is a static export (`output: "export"` in `next.config.js`) hosted on GitHub Pages at `grgsferry.github.io`.

```bash
npm run deploy
```

This builds the site into `/out` and pushes it to the `gh-pages` branch, which GitHub Pages serves.

Branches:

- `main` — Next.js source (this code)
- `gh-pages` — built site, generated by `npm run deploy`; don't edit by hand
- `master` — legacy Create React App version

Blog markdown is read at **build time** via `generateStaticParams`, so it works with static export. Any post in `/posts` gets published on the next deploy.
